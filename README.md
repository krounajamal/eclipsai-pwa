# ECLIPSAI PWA

Multilingual mobile-first PWA showcase (Arabic, French, English), with a black/silver/violet visual identity.

## Publish with GitHub Pages
1. Upload the contents of this folder to the repository root.
2. In GitHub open Settings → Pages.
3. Under Build and deployment select Deploy from a branch.
4. Select `main` and `/(root)`, then Save.
5. The expected URL is https://krounajamal.github.io/eclipsai-pwa/

## Google Search
After the site is live, add its URL in Google Search Console, verify ownership, submit `/sitemap.xml`, then inspect the homepage and request indexing.

Indexing is not guaranteed or immediate. The feature cards are a showcase only; connect AI services through a secure backend before advertising them as functional. Never put API keys or passwords in this public repository.
